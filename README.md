# Windows 桌面图标修复与防复发工具

一键修复 Windows 桌面快捷方式与应用程序图标显示为白块、无法正常显示、关联错误等异常，并优化图标缓存池以防止故障复发。

---

## 适用场景

- 桌面 `.lnk` 快捷方式或应用图标异常变为通用白色文件图标（白方块）。
- 网页快捷方式（`.url`）或可执行程序（`.exe`）文件类型关联丢失。
- 清除快捷方式小箭头/角标时误操作导致残留黑色或白色方块。
- 系统图标缓存损坏或容量溢出导致的频繁掉图标。

---

## 核心功能与修复原理

1. **缓存彻底清理**  
   先安全终止 `explorer.exe` 解锁文件句柄，再深度清除 `%localappdata%` 下的 `IconCache.db` 以及 `iconcache_*.db`、`thumbcache_*.db` 缓存数据库。

2. **清除用户层注册表劫持与覆盖**  
   清理 `HKCU\Software\Classes` 与 `FileExts` 下对 `.lnk`、`.exe`、`.url` 的错误覆盖与影子键值，消除因用户级覆盖引发的未关联现象。

3. **重建核心系统关联与图标处理器**  
   在系统级注册表（`HKLM`）中准确配置 `exefile`、`lnkfile` 与 `InternetShortcut` 的标准关联、`IconHandler` 与 `DropHandler` CLSID。

4. **去除异常角标残留**  
   移除注册表 `Shell Icons\29` 异常键值，杜绝因第三方美化工具修改角标失败引发的白色背景方块。

5. **缓存扩容防复发**  
   将系统最大图标缓存池容量（`Max Cached Icons`）扩容至 `8192`，有效降低后续因安装软件过多再次损坏缓存的概率。

6. **自动提权与无损刷新**  
   内置免交互 UAC 管理员提权检测；重启资源管理器后通过 `ie4uinit.exe -show` 刷新桌面视觉，不破坏系统原生运行库。

---

## 使用方法

1. **直接运行**：双击运行 `Desktop Icon Restore Tool.bat`。
2. **确认权限**：若弹出用户账户控制（UAC）提示，点击“是”授予管理员权限。
3. **等待完成**：程序自动完成缓存清理、注册表修复与资源管理器重启，修复完成后将在 2 秒内自动退出。

---

## 注意事项

- 运行期间桌面和任务栏会短暂消失 1~2 秒（资源管理器正在重启并重建缓存），属于正常现象。
- 本工具仅修复系统图标映射与缓存机制，不修改用户个人文件或应用程序本体数据。
